# MOOC STM32CubeIDE dual core STM32WL55

WARNING  : 
    This material has been created in 2021 and is delivered as it is.

## MOOC purpose 

Learn basic principles concerning dual core project creation and debug on STM32WL55
Get practical skills on creation, configuration and run dual core based STM32WL55 MCUs using STM32CubeIDE toolchain.

## Prerequisites
- NUCLEO-WL55JC2 board
- Micro-USB cable
- PC with preinstalled the following software:
    - STM32CubeIDE (in version at least 1.5.0)
    - STM32WL Cube library (in version at least 1.0.0) -> to be installed from STM32CubeIDE (help -> Manage Embedded Software Packages -> STM32Cbe MCU Packages)
